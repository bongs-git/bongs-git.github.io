Set it up (about five minutes)

  1. Make an account at elevenlabs.io and pick a plan. The smallest paid plan is enough to begin.
  2. In ElevenLabs, create an API key. If it asks what the key may do, allow Text to Speech and reading Voices.
  3. In Supabase, add it as the secret ELEVENLABS_API_KEY.
  4. Come back here and reload.
